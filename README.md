# Regatta PD

Website for Regatta Professional Development, built with [Astro](https://astro.build).

## Live Sites

| Site | URL |
| :--- | :--- |
| **Demo Site** | https://regattapd.netlify.app/ |
| **Design Preview** | https://playful-frangollo-d4c2cb.netlify.app/ |

## Design

The `Design/RegattaPD-Claude-Design/` folder contains exported files from [Claude Design](https://claude.ai/design) — the visual design source for this project.

## Commands

All commands run from the project root:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Install dependencies                             |
| `npm run dev`             | Start local dev server at `localhost:4321`       |
| `npm run build`           | Build production site to `./dist/`               |
| `npm run preview`         | Preview build locally before deploying           |
